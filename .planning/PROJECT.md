# Project: Streaming Platform Upload

**Vision:** Secure video upload and playback platform with Google authentication, role-based access, and hardened API controls.

**Core Value:** Store, manage, search, view, and download videos with least-privilege access and strong server-side enforcement.

**Primary Constraints:**
- Preserve the existing Next.js App Router architecture.
- Keep authorization decisions on the server, not in client state.
- Apply rate limiting and secure session handling from the start.
